# Decisions register (2026)

Rulings that future releases must respect. Facts live on entity pages; this page records *decisions about those facts*.

> Fictional example.

## A. Fact rulings

1. **Total years: 7+**, computed from the employer timeline as of 2026-01. Channels may round up phrasing ("over seven years") but not the number.
2. **Consultancy roles are sequential**, not parallel — see `employer-nexo`.
3. **The current client may be named** in profiles; the client's internal system names may not.
4. **One early role is real but never published** — omitted for relevance, not because it is untrue.

## D. Lessons

- A seniority word in a draft is a claim, not a style choice. It belongs in a ruling, once.
- Limits belong to the destination. The moment one is copied into a fact page, this register stops being trustworthy.
