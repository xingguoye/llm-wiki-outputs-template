## What this excerpt does not do

- It does not write the dates freehand — they are copied from `employer.md`, which owns them.
- It does not put the client in the organization field. The organization stays the employer of record.
- It does not name a seniority level beyond the one the register allows.
- It does not restate the totals; "over seven years" is a rendering of the person page's `7+`.

## When something is wrong here

If a number or a title is wrong, the fix goes into the wiki page and the draft is re-rendered. Editing this file to correct a fact is the one edit that breaks the model (see `METHOD.md` §3, law 4).
