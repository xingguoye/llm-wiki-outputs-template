# 决定登记簿（2026）

后续发布必须遵守的裁定。事实住在实体页；本页记录的是*关于那些事实的决定*。

> 虚构示例。

## A. 事实裁定

1. **总年限：7+**，由雇主页的时间线按截至 2026-01 计算。渠道可以润色措辞（"超过七年"），但不能改数字。
2. **咨询项目是先后接续的**，不是并行——见 `employer-nexo`。
3. **当前客户可以点名**写到档案里；客户内部的系统名不可以。
4. **有一段早期经历是真的，但永不对外发布**——省略是因为相关性，不是因为它不真实。

## B. 渠道规则去哪了

| 主题 | 住在 |
|---|---|
| 字符上限、裁剪顺序 | `outputs/linkedin/SPEC.md` §3 |
| 职位名的译法 | `outputs/linkedin/SPEC.md` §6 |
| CV 页数、ATS 约束 | `outputs/cv/SPEC.md` §3 |

这张表存在的意义：读者记得"我们在某处定过这件事"时，一跳就能找到，而那条决定不会漏回事实页。

## C. 变更日志

| 日期 | 变更 |
|---|---|
| 2026-01-05 | 登记簿建立；记录裁定 1–4 |

## D. 教训

- 草稿里的资历词是一条断言，不是风格选择。它只属于裁定，且只写一次。
- 上限属于去处。它一旦被抄进事实页，这份登记簿就不再可信。
