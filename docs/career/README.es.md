# Ejemplo completo (ficticio)

Todo lo de aquí es inventado: nombres, empresas, fechas. Existe para mostrar cuatro convenciones en uso, porque las reglas de la plantilla se leen de forma abstracta hasta que las ves aplicadas.

| Archivo | Muestra |
|---|---|
| [`person.md`](person.md) | la página que posee los totales transversales (años, nivel, idiomas) |
| [`employer.md`](employer.md) | la página que posee los periodos de empleo: el único lugar donde viven las fechas |
| [`position.md`](position.md) | un puesto: periodo + modalidad + atribución de cliente + IDs de afirmación opcionales |
| [`decision-register.md`](decision-register.md) | resoluciones que no deben volver a discutirse en cada publicación |
| [`linkedin-draft-excerpt.md`](linkedin-draft-excerpt.md) | cómo un borrador cita hechos por slug y mide sus propios límites |

Léelos en ese orden: totales → periodos → un puesto → las resoluciones → el texto renderizado.

Dos cosas que conviene notar:

1. **El borrador no repite ni una fecha.** Dice "el puesto actual" y deja que el wiki posea el periodo.
2. **El registro de decisiones es aburrido a propósito.** Su trabajo es evitar que la misma discusión se repita, no documentar el razonamiento con elegancia.
