# raw/ — immutable sources

Drop originals here: PDFs, docx, transcripts, exported notes, old CVs, screenshots of feedback.

Rules:

- **Never edit a file in here.** If a source is wrong, note it on its `wiki/sources/` page; don't correct the artifact.
- **Never commit it.** The `.gitignore` in the repo root ignores everything except this README. PII lives here and only here.
- **Name for retrieval**, not for beauty: `2026-11-cv-es.docx`, `2026-10-call-acme.md`.
- One file = one summary page under `wiki/sources/`.

This directory is evidence, not knowledge. The knowledge is in `wiki/`.
